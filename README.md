# STAT 105 Lab 6

See [INSTRUCTIONS.md](INSTRUCTIONS.md). Code is in [stat105-lab6.R](stat105-lab6.R).

## Setup

Requires [R](https://cran.r-project.org/). [RStudio](https://posit.co/download/rstudio-desktop/) is optional.

```sh
git clone https://github.com/andrianllmm/stat105-lab6.git
cd stat105-lab6
```

## Run

**Command line:**

```sh
Rscript stat105-lab6.R
```

**RStudio:** open `stat105-lab6.Rproj`, then open `stat105-lab6.R` and click **Source** (or press `Ctrl+Shift+S`).

Outputs (CSVs and figures) are written to `outputs/`.
